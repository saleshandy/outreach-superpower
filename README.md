# Saleshandy Superpowers

AI-powered outreach toolkit for SDRs, AEs, and founders. Coming soon.

## Install

```
/plugin install saleshandy-superpowers
```

## Skills

- `using-saleshandy-superpowers` - auto-router (loads first)
- `strategy-architect` - extract outreach strategy from a website
- `icp-builder` - build & version your ICP
- `service-productizer` - turn services into productized offers
- `email-sequence-generator` - generate cold email sequences for Saleshandy
- `email-auditor` - score & improve cold email copy
